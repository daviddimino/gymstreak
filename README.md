# GymStreak

A gym accountability app where friends compete on gym attendance — iOS-first prototype.

**Live app:** https://daviddimino.github.io/gymstreak/ *(update if your repo name/user differs)*

This is a single self-contained `index.html` — no build step, no dependencies. It's an
installable PWA: open the live URL in Safari on iPhone → Share → **Add to Home Screen**
to launch it fullscreen like a native app.

## Screens
Onboarding · Home (dark + light) · Active session · Session summary · Leaderboard ·
Friend profile · Friends · Activity feed · Profile/Settings.

Prototype only — sample data, no backend or persistence.
